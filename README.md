# 随对话更新会话标题 · Snow App 脚本插件

<img src="assets/icon.svg" alt="" width="72" height="72">

每轮对话结束后自动把会话标题改成能概括聊天内容的名字；同时提供会话右键的「AI 重命名」与一个设置浮层。

- 单文件客户端脚本，无需打包、无需构建；
- 只读写会话标题，不发消息、不改消息内容；
- 在 Snow App「插件 → 插件列表 → 脚本插件」里管理。

## 安装

### 插件市场（推荐）

Snow App → 侧边栏「插件」→ **插件市场** → **脚本插件** → 找到「随对话更新会话标题」→ 安装。

### 手动安装

1. 下载本仓库 Release 里的 `snow-auto-title-<version>.user.js`；
2. Snow App →「插件」→ 插件列表 → **脚本插件** → 安装（选择该文件）。

## 使用

| 场景 | 怎么做 |
| --- | --- |
| 自动改名 | 保持「启用自动命名」打开，每轮回复结束后自动更新标题 |
| 手动改名 | 会话条目右键 / 「⋯」→ **AI 重命名** → 预览、可改字、Enter 应用、Esc 取消 |
| 改设置 | 「AI 重命名」浮层右上角的「自动命名设置」，或脚本命令（插件列表里） |

### 设置项

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 启用自动命名 | 开 | 关闭后完全停止订阅，只保留右键手动 |
| 标题来源 | AI | AI 失败时自动回退本地规则 |
| 长度上限 | 32 | 4–48 字符，截断不劈开英文单词 |
| 采样片段数 | 5 | 3–8；首条 + 中段等距 + 最近一问一答 |
| 最少消息数 | 2 | 太短的会话不改名 |
| 冷却 | 60s | 同一会话的最小间隔 |

### 自动改名的触发条件

会话离开运行集合 → 延迟 1.6 秒 → 依次检查：非子代理会话、开关开启、连续失败 < 3（失败 30 分钟后解封）、冷却、消息数增长、有用户消息。任一不满足就跳过，不发请求。**标题与当前一致不算失败**，只推进消息数。

## 隐私

只读四个元数据域并通过网络发往你配置的模型，只写会话标题：

- `conversations`（标题、消息数）
- `messages`（生成标题所需的对话片段）
- `apiKeys`（调用你配置的模型）
- `customHeaders`（档案绑定的自定义请求头，如 `x-opencode-session`）
- `network`（把抽样片段发给当前激活档案的模型服务）

发送给模型的内容是**抽样后的对话片段**（约 1.5k 字，与会话总长无关），不发完整历史、不发项目文件。网络请求只发往你当前激活的 API 档案。

## 兼容性

- 需要 Snow App 的客户端脚本能力（`@snow-target client`、`snow.metadata` / `snow.write`）；
- 默认沙箱档即可运行（不需要完全权限）；脚本不读取 `window.snow`；
- **不要与面板插件版同时启用**（面板插件版已归档，仅在需要回滚旧形态时使用）；
- 与在同一会话右键菜单里注入「AI 重命名」的其他脚本可能重复，出现两组菜单项时停用其中一个。
